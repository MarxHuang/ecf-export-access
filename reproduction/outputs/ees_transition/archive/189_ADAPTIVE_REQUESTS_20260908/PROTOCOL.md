# Participant-local experiential request adaptation

This additional sensitivity leaves the ECF update, network model, allocation implementation, original profile mapping, 418 export participants, 80 assessment dates, load scale 0.30, PV scale 5.881304516313253, and nominal feedback gain 0.5 unchanged. It does not replace the primary results.

Each participant chooses a multiplier from {0.50, 0.75, 1.00, 1.25, 1.50} applied to its original history-based request, capped at registered capacity. The participant observes only its own completed delivery. Its bounded reward is delivery divided by its own registered capacity, corresponding to delivery maximization at the original zero shortfall cost. This is not a monetary benefit estimate. The Exp3 probability update uses exploration 0.10, following the update in Auer et al. (2002), SIAM Journal on Computing 32(1), 48–77, Fig. 1, DOI 10.1137/S0097539701398375. No bandit regret guarantee, Nash equilibrium, incentive compatibility, or foresighted response is claimed for the stateful multi-participant system.

ADAPTIVE updates action preferences from own delivery. STATIC_RANDOM uses the same initial uniform action distribution and the same random draws but never updates preferences. Seeds 2001, 2002, and 2003 are fixed before network evaluation; all are reported. The seed replicates reuse the same network and dates, not independent feeders or extra observed dates. The choice set and exploration parameter are sensitivity assumptions, not behavior calibrated from field data or selected for positive ECF outcomes.

NO_FEEDBACK, ECF, and UNQUALIFIED_SAME_UPDATE evolve separate participant preferences from their own branch outcomes. The unqualified control changes ceilings after any unused award using exactly the same update formula as ECF but without replay qualification. MATCHED_UNIFORM_SHADOW uses the current ECF raw requests and removes the same total request as ECF; it has no independent learning branch. Its contrast identifies current targeting conditional on the ECF trajectory, not the long-run effect of an independently deployed uniform policy.

Preferences and request ceilings persist across midnight within each of the ten truly contiguous observed date blocks (maximum 35 days). Both reset at the start of a block; missing calendar dates are not stitched together. The physical model is freshly initialized daily. A fixed-reference mode with multiplier one is used only to check reproduction of the original first-day results before the full sensitivity is launched.

All physical failures, negative contrasts, null intervals, and seed outcomes are retained. No parameter or mapping is selected on the resulting pass rate or delivery gain. The original nonlinear AC predicates and numerical tolerances apply, including the existing absence of native line-ampacity evidence. No native conductor rating or field-telemetry claim is introduced.

Planned output: paired ECF-minus-control energy contrasts by date, block, seed, and behavior mode; all-seed pooled mean per original date; change in these contrasts between ADAPTIVE and STATIC_RANDOM; participant action probabilities and effective requests; ceiling persistence; all authorization/delivery/replay physical checks. Date-dependent uncertainty uses the existing calendar-distance Bartlett kernel with width eight days, 10,000 antithetic draws, seed 189. Average across the three algorithm seeds within each date before uncertainty calculation; do not treat seeds, participants, or half-hours as independent observations. Report seed-specific contrasts and block totals alongside uncertainty.
