# 记录误差下界接口与固定配对检验

本轮解决一个明确的实现问题：主文式(32)的下界尚未进入原实验控制接口。新接口不接收真实可用出力，只接收完成授权、计量交付、重放授权、事后记录、显式误差半径和单独的物理有效性标志。误差半径缺失或记录无效时不得默认为零误差。

先实现并单独测试该接口，再检查全部原始80日×48半小时配对。原配对及原物理结果固定，不运行新分配或反馈轨迹。这一步用于区分“交付恢复判定误触发/漏检”和“新控制轨迹收益”，不得把前者写成后者。

计算前规定六种有界记录偏差：误差半径分别为注册容量的1%、5%、10%，分别采用所有参与者共同正偏差和共同负偏差。记录为max(完成交付,真实可用出力±半径)。注册容量不是仪表精度；比例为预设压力水平，不是根据当前误触发结果挑选。真实可用出力仅由检验器构造扰动和核对真值，不能进入被测控制接口。

对全部3840个配对报告：真实交付恢复判定、点记录判定、下界判定、误触发、漏检、真阳性、真阴性。四类判断使用相同完成授权、交付、重放授权及组外访问释放条件；全部配对的既有物理结果通过，仅用于保持原配对合法，不能证明记录误差盒内的AC可行性。误触发的含义仅为“不满足真实交付恢复条件却判定满足”，不是对人群行为的分类准确率。

计算前锁定本说明、接口、测试和分析脚本及来源文件哈希。零半径准确记录必须复现原全部判定。随机和离散精确测试检查：下界逐分量不超过真值；下界通过蕴含真实恢复通过；半径增大不得使已失败的固定配对转为通过；缺记录、缺半径、非法维度、非有限值、负值和与计量矛盾的误差界需拒绝或关闭。

保留全部六组及全部时段，不因零、负或无区别结果删除设置。不改174轮正文、SI、原图或原数据。本轮结果将决定后续新反馈轨迹需要验证什么，而不是直接增加一个成功率主张。
