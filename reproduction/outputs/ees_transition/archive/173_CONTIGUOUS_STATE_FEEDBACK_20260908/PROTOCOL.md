# 跨日状态反馈：计算前固定方案

采用原80个主要评价日期，按实际相邻日历日期分为连续日段。段内上限状态从上一日第48个半小时更新后传入下一日第1个半小时；仅在段首初始化到注册容量。不填补缺测日期，不把不相邻日期拼成“连续80天”。不重新选择数据、映射、负荷、光伏容量、网络限值、物理检查阈值或请求生成方式。

比较保留三档既有增益0.25、0.5、1的ECF与相应逐时段等总量对照。等总量对照必须用本次ECF请求重新生成，不沿用每日重置的旧对照。增益0.5同时计算同更新律但不用重放判定的对照，保持其自身跨日状态。无反馈不携带状态，用原始同日期结果比较。每天重新初始化静态OpenDSS模型，与原实验保持一致；本实验只改变请求上限在日界面的处理，不研究调压器/储能内部物理状态记忆。

主要问题：日间初始化是否实质影响ECF交付、增益反转、以及保留重放判定的比较结果。全部日期和全部设置均保留，包括零/负差值、未通过物理检查和模型错误。没有以结果有利为依据的删除、重选增益或网络参数修改。

输出逐时段控制记录及逐连接上限、目标、请求、授权、交付、可用出力和日末状态；独立核验日界面传递、更新律、容量界、能量恒等式、等总量、实际/授权/重放物理检查。每个连续段首日与原每日重置结果的请求、授权、交付、上限逐连接复现；其他日不应强迫结果匹配。

主要统计为全部80日的能量合计与成对日差值，同时分别给出连续段合计和最长实际日段。不能将参与者或半小时视为独立网络样本。日期依赖wild区间沿用日历距离三角核、带宽7日、10000次反对称重复；跨日记忆可能超过该带宽，因此此区间作为同口径描述，补充全部连续段的方向和范围，不据10个不等長日段宣称普遍长期稳定。

增益0.5的ECF与无重放判定对照为主要新比较，0.25/1为既有增益敏感性延伸。先固定上述问题、增益、日期和统计，再计算新结果。没有新的参与者适应行为模型，因此本实验不证明激励相容或参与者预期反馈的反应。

计算无预设最长运行时。中断时只从已完成且哈希验证的日检查点恢复，必须读入该日最终上限，不从容量重新开始。工作按独立日段和控制设置并行，不按同一日段内各天并行。
